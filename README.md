# Tournament Tally

Primero la clasificacion global de Anotadores esta en Extras.Por tanto ahi es la suma de todos los pts de cada torneo, ahora mismo tiene que estar reincidado. Despues en Extras el punto es que ha simple vista te aparezca el top 5 de ese topico pero al clickar te enseña todo el top de esto, menos en rivalidades que no voy a poner todas las rivalidades. Y quiero que hagas una base de datos es decir yo quiero esto. Varios tendran el enlace y podran entrar para ver como va la competicion, y el que tenga acceso admin podra cambiar las cosas y al hacerlo a todos con el enlace les saldra el cambio. como si fuera una presentacion de google entiendes.
